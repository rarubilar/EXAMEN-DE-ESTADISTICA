# Examen de Estadística · Por el 7 en Estadística

Árbol de estudio interactivo para preparar la sustitutiva de Estadística I (2026).

**Abrir:** https://rarubilar.github.io/EXAMEN-DE-ESTADISTICA/

Incluye 6 unidades y 23 temas con lecciones, 69 ejercicios con corrección inmediata, formulario con la tabla normal, práctica de «¿qué distribución es para qué?», un simulacro con nota y una presentación de 8 láminas.

Es un solo archivo HTML (`index.html`) que también funciona sin internet. El código fuente está en `src/`; para regenerarlo: `python src/build.py`.
